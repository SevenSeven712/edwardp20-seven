cococalc Java · 编译原理

这个项目没有使用简单的 eval()，而是完整实现了一个编译器前端的经典流水线。它通过词法分析和语法分析，将人类可读的表达式转换为计算机易于计算的格式。

  • 词法分析 (Tokenizer)： 扫描输入字符串，将字符流拆解为一个个 Token（数字、运算符）。
  • 语法分析 (Yard)： 采用调度场算法（Shunting-yard）。利用栈和优先级表，把中缀表达式（如 1 + 2）转为后缀表达式（如 1 2 +，即逆波兰式）。
  • 求值 (Coco)： 遍历后缀表达式，遇到数字就压栈，遇到运算符则弹出两个元素计算，再将结果压栈，最终得出结果。
  • 精度保障： 底层采用 BigDecimal 而不是普通的 double，完美避免浮点数精度丢失。

-JAVA- Java · 控制台交互

基础的面向新手控制台练手项目，实现了经典的猜数字游戏。

  • 使用 java.util.Scanner 接收用户输入。
  • 使用 java.util.Random 生成 1-100 的随机目标数字。
  • 在 while 循环中，通过 if-else 判断输入大小并提示，直到猜中为止。

libihatelogs Java · 极简库

因为反感现代日志框架（如 Log4j）的臃肿而手写的轻量级日志库，零第三方依赖。

  • NIO 写入： 底层的 LogWriter 直接调用 Java NIO 的 Files.writeString。
  • 追加模式： 指定 StandardOpenOption.CREATE（不存在则创建）和 StandardOpenOption.APPEND（追加写入），实现日志持久化。
  • 级别分发： 对外暴露统一的 autoLog 接口，内部根据级别（fatal/error/info）解耦到不同的处理器。

myjava-app Java · 构建工具

用于学习现代 Java 工程构建与 CI/CD 的练手项目。

  • 采用 Gradle 作为构建工具（使用 Kotlin DSL 编写 build.gradle.kts）。
  • 配置 ShadowJar 插件，将所有依赖打包进单一的 Fat Jar，方便直接运行。
  • 包含 JUnit 单元测试。
  • 配置 GitHub Actions，每次提交代码自动触发测试与打包流程。

proot C · 系统调用

让你在没有 root 权限的 Linux / Android 上运行 chroot 的核心工具。

  • 利用 Linux 的 ptrace（进程跟踪）系统调用。
  • 在用户态拦截进程对文件系统的访问请求，并动态重定向路径。
  • 通过伪造根目录环境，让程序以为自己在独立的文件系统中运行，从而不需要特权即可运行完整 Linux 发行版。

termux-app-multiusers Java · Android

Termux 的多用户隔离分支。

  • 修改了 Termux 在 Android 原生的用户级隔离逻辑。
  • 允许在同一台设备上创建多个相互独立的 Linux 用户环境（不同的环境变量、软件包、主目录），互不干扰。

tiny_computer_lotofpermission Dart · 移动端虚拟化

在 Android 上点击即用的完整 Debian 桌面环境（Fork）。

  • 基于 Dart 开发 Android 前端。
  • App 内部打包了一个完整的 Debian 12 (ARM64) Rootfs 镜像。
  • 利用 PRoot 技术挂载该镜像并运行系统。
  • 通过 XSDL / VNC 等图形协议，将内部的 XFCE 桌面渲染到手机屏幕上，实现类似 PC 的体验。

bug-free-eureka CI/CD · 云端构建

这是一个没有业务代码的纯构建仓库。

  • 利用 GitHub Actions 的免费服务器算力。
  • 通过 .github/workflows/build.yml 脚本，定时拉取 MobileGL 源码并在云端完成编译。
  • 解决了本地构建环境配置繁琐的问题。

edk2-nightly2 CI/CD · 固件编译

UEFI 固件（EDK II）的夜间自动构建节点。

  • UEFI 源码庞大且编译环境极其复杂。
  • 利用 GitHub Actions 设定定时任务（Cron）。
  • 每晚自动拉取官方最新源码，配置编译环境并在云端执行编译，生成每日固件。

edwardp20.github.io HTML/JS · 静态博客

完全托管于 GitHub Pages 的无后端动态博客。

  • 文章链接形如 viewer.html?md=2.md，利用 URL 查询参数（Query String）传递文件名。
  • viewer.html 中的 JS 读取参数后，通过 fetch API 请求同目录下的 Markdown 文件。
  • 引入 CDN 版 marked.js，将 Markdown 文本实时转换为 HTML，并注入到 DOM 中。
  • 通过仓库根目录的 CNAME 文件，将自定义域名绑定到 GitHub Pages。
